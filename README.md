# My Toolkit

A small command-line toolkit written in Python. Choose from three simple tools in an interactive menu.

## Requirements

- Python 3

## Run the program

Open a terminal in the project folder and run:

```text
python toolkit.py
```

On some Windows installations, use `py toolkit.py` instead.

## Tools

1. **Number guessing game** — Guess the randomly chosen number from 1 to 20. The game tells you whether each guess is too high or too low.
2. **Simple calculator** — Enter two numbers and choose addition (`+`), subtraction (`-`), multiplication (`*`), or division (`/`).
3. **To-do list** — Add tasks, view the tasks you've added, or clear the list. The list is kept while the program is running.

Select a tool by entering its menu number. Choose **4** to quit. Invalid menu choices display a message and return to the menu.
